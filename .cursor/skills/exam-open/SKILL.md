# Открытый текст ответа

Ответ по конспектам в `Материал_тексты`. Не читать все `.md` подряд и не пересобирать индекс.

1. Вытащи 3–6 редких слов вопроса (термины, номера законов, имена) и прогони Grep по `Материал_тексты`.
2. Запусти `python rag/search.py` с полным текстом вопроса.
3. Пиши только по кускам из Grep и из топа поиска.

Форма ответа:

- Связный текст в учебном стиле, без воды и без догадок вне конспекта
- В конце файл и заголовок кусков, на которые опирается текст

Если в материале этого нет, так и напиши. Не достраивай ответ общими знаниями.
