# Общий режим задания

Ответ по конспектам в `Материал_тексты`. Не читать все `.md` подряд и не пересобирать индекс.

1. Вытащи 3–6 редких слов вопроса (термины, номера законов, имена) и прогони Grep по `Материал_тексты`.
2. Запусти `python rag/search.py` с полным текстом задания.
3. Сначала назови форму задания (сопоставление, несколько верных, верно/неверно, вставить термин или другая). Потом ответь в той же форме.
4. Опирайся только на куски из Grep и из топа поиска.

В конце укажи файл и заголовок. Если в материале этого нет, так и напиши. Не угадывай по общим знаниям.
