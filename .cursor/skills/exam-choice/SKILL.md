# Выбор одного ответа

Ответ по конспектам в `Материал_тексты`. Не читать все `.md` подряд и не пересобирать индекс.

1. Вытащи 3–6 редких слов вопроса (термины, номера законов, имена) и прогони Grep по `Материал_тексты`.
2. Запусти `python rag/search.py` с полным текстом вопроса, включая варианты.
3. Сверь варианты только с кусками из Grep и из топа поиска.

Форма ответа:

- Верный вариант одной строкой
- Одно-два предложения, почему
- Файл и заголовок куска

Если в материале этого нет, так и напиши. Не угадывай по общим знаниям.
