# Конспекты: RAG для экзамена

Учебный поиск по 10 markdown в `Материал_тексты` (понятный язык, обращения граждан). Ответы пишет агент Cursor. Gemini только считает векторы. Локальных моделей и torch нет: скрипты на стандартной библиотеке Python.

## Модель

Пробник (`python rag/index_build.py --probe`) видит три id: `gemini-embedding-001`, `gemini-embedding-2`, `gemini-embedding-2-preview`. На этом ключе все три вернули вектор размерности 768. В индексе записана `gemini-embedding-001`: стабильная и принимает пачку кусков с `task_type` (`RETRIEVAL_DOCUMENT` для текстов, `RETRIEVAL_QUERY` для вопроса). Чат-модели эмбеддинги не делают.

Ключ: `GEMINI_API_KEY` в `.env`. Файл в `.gitignore`. В `rag/index.json` секретов нет.

## Как устроено

- `rag/chunk.py` режет markdown по `#` / `##` / `###`. Секция длиннее ~1500 символов делится по абзацам. Сейчас 188 кусков.
- `rag/gemini_http.py` ходит в `generativelanguage.googleapis.com`. На 429 и 5xx ждёт и повторяет.
- `rag/index_build.py` собирает `rag/index.json` пачками по 8. Повторный запуск не пересчитывает куски с тем же id и той же моделью. Смена модели пересчитывает всё.
- `rag/search.py "вопрос"` делает один запрос за вектором вопроса и печатает топ-8 (счёт, файл, заголовок, текст). Косинус считается в чистом Python.

Пересборка после правки конспектов: `python rag/index_build.py`.

## Скиллы агента

В `.cursor/skills/`. Перед ответом не читать все `.md`: Grep по 3–6 редким словам и `python rag/search.py` с полным текстом вопроса.

- `exam-choice` — один верный вариант и короткое обоснование
- `exam-open` — связный текст ответа
- `exam-general` — сопоставление, несколько верных, верно/неверно и прочие формы

Пробный вопрос «метакогнитивная ловушка» первым куском возвращает `Материал_тексты/ПЯ_24.08.2026.md`, раздел про мышление. Grep по «метакогнитивн» попадает в тот же файл.
